Репозиторий содержит решения практических заданий по базовым конструкциям языка Python: обработка строк, работа со списками, словарями и множествами, файловый ввод-вывод, а также сериализация данных (`pickle`, `json`).

- **Python 3.10+**
- **ОС:** Windows 10/11 или Linux/macOS

## Список задач

| № | Файл | Описание задания |
| :-: | :--- | :--- |
| **1** | `task_01.py` | Результат выполнения выражений из варианта (срезы строк и списков, удаление пробелов). |

| **5** | `task_05.py` | Создание и наполнение множеств (`set`) различными способами. |
| **6** | `task_06.py` | Дозапись текста в файл и подсчет количества строк в нем. |
| **7** | `task_07.py` | Сериализация списка в бинарный файл и чтение через модуль `pickle`. |
| **8** | `task_8.py`  | Сериализация словаря в файл и чтение через модуль `json`. |

## Инструкция по запуску

### 1. Запуск через главный модуль (`main.py`)

Запустите программу:
```bash
python main.py
```

В терминале отобразится меню со списком доступных задач и приглашением к вводу:
```text

Список доступных задач:
    1. Результат выполнения выражений из варианта
    2. Разделение строки по четным и нечетным индексам
    3. Слияние списков
    4. Добавление элементов в словарь
    5. Создание и работа с множествами
    6. Работа с файлом и подсчет строк
    7. Сериализация списка через pickle
    8. Сериализация словаря через json
    9. Выход из программы
Введите номер задачи (1-8) или 9 для выхода:
```

- Введите **номер задачи** (например, `3`), чтобы запустить конкретное решение.
- Введите **9**, чтобы выйти из программы.
